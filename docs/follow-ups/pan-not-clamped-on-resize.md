# 창 크기를 줄이면 이동량이 제한 범위를 벗어남

- **증상:** 확대한 채 지도를 가장자리까지 끈 뒤 창을 좁혀 지도 반지름이 줄어도, 저장된 이동량은 다시 제한되지 않는다. 다음 확대·축소나 드래그 전까지 하늘 원이 화면 밖으로 치우쳐 보일 수 있다.
- **근거:** `features/starmap/chart-viewport.ts`의 `clampPan`은 확대·축소와 드래그 때만 호출된다. 리뷰(`code-review low`)가 지적했고 코드 읽기로만 확인했으며 런타임에서 재현하지는 않았다.
- **스펙 기준:** `docs/specs/starmap-sky-chart/spec.md`의 가정 "이동은 하늘 원의 가장자리가 화면 가장자리를 넘어가지 않는 범위로 제한한다".
- **다음 조치:** 반지름이 바뀔 때 이동량을 다시 제한하거나, 이동량을 반지름에 대한 비율로 저장한다.
